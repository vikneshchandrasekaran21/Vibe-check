# Weekly law and standards updates

A checklist for the weekly pass on everything in vibe-check that depends on laws, regulators or published standards. For each row:
1. Open the official source (the regulator, court, legislature or standards body; not a blog).
2. If something changed, update the module and add a line to `CHANGELOG.md`.
3. Write today's date in **Last verified** (`YYYY-MM-DD`) and the source link in **Notes**.

`scripts/validate.py` warns (without failing) about rows never verified or not verified in the last 30 days, so every release shows what's due.
